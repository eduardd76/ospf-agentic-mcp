Problem: OSPF neighbor stuck in INIT state  
Root Cause: Authentication mismatch

Explanation:
One side is configured with MD5 authentication while the other is not, or the keys don’t match.

CLI Diagnosis:
- show ip ospf neighbor
- debug ip ospf adj
- debug ip ospf packet

Fix:
interface Gi0/1
 ip ospf authentication message-digest
 ip ospf message-digest-key 1 md5 MySecret123

Validation:
Both neighbors must have matching authentication. Check adjacency state reaches FULL.
